# masters_degree_repository

## Docker Reproducibility Setup

This repository includes a Docker setup for reproducible benchmark execution.
The goal is toolchain and runtime consistency, not full embedded-device simulation.

### What Is Included

- `Dockerfile`: fixed environment with `gcc`, `make`, OpenSSL 3, and PowerShell.
- `docker/run_all.sh`: runs the full benchmark suite and exports CSV files.
- `docker-compose.yml`: one-command run with configurable CPU/RAM limits.
- `results/`: output directory (mounted from host).

### Build

```bash
docker build -t lwc-bench .
```

### Docker Compose (recommended)

Run with defaults (`CPUSET=2`, `CPUS=1.0`, `MEM_LIMIT=512m`):

```bash
docker compose up --build
```

PowerShell example:

```powershell
docker compose up --build
```

Override limits and benchmark parameters:

```bash
CPUSET=2 CPUS=1.0 MEM_LIMIT=512m RSA_BITS_LIST="2048 3072 4096" CLEAN_RESULTS=0 docker compose up --build
```

PowerShell example:

```powershell
$env:CPUSET="2"
$env:CPUS="1.0"
$env:MEM_LIMIT="512m"
$env:RSA_BITS_LIST="2048 3072 4096"
$env:CLEAN_RESULTS="0"
docker compose up --build
```

### Run (recommended)

Use a fixed host CPU core for lower scheduling noise:

```bash
docker run --rm --cpuset-cpus=2 -m 512m -v "$(pwd)/results:/opt/project/results" lwc-bench
```

PowerShell example:

```powershell
docker run --rm --cpuset-cpus=2 -m 512m -v "${PWD}/results:/opt/project/results" lwc-bench
```

### Optional Parameters

Set RSA sizes (default is `2048 3072`):

```bash
docker run --rm --cpuset-cpus=2 -m 512m \
  -e RSA_BITS_LIST="2048 3072 4096" \
  -v "$(pwd)/results:/opt/project/results" \
  lwc-bench
```

PowerShell example:

```powershell
docker run --rm --cpuset-cpus=2 -m 512m `
  -e RSA_BITS_LIST="2048 3072 4096" `
  -v "${PWD}/results:/opt/project/results" `
  lwc-bench
```

Keep previously generated files in mounted `results/`:

```bash
docker run --rm --cpuset-cpus=2 -m 512m \
  -e CLEAN_RESULTS=0 \
  -v "$(pwd)/results:/opt/project/results" \
  lwc-bench
```

PowerShell example:

```powershell
docker run --rm --cpuset-cpus=2 -m 512m `
  -e CLEAN_RESULTS=0 `
  -v "${PWD}/results:/opt/project/results" `
  lwc-bench
```

### Produced Artifacts

- `run-metadata.txt` with environment and run parameters.
